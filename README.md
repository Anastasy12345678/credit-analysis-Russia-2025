
# Анализ объема выданных кредитов и задолженности населения по регионам в 2025 году в России

## Синопсис
Россия сегодня находится в состоянии турбулентности на рынке. Оценить экономическую ситуацию и выстроить прогноз на ближайшие годы можно с помощью исследования отдельных компонентов рынка, одним из которых выступает кредитование физических лиц. 
Цель данного проекта – проанализировать статистику выдачи кредитов физическим лицам в России за 2025 год, а также задолженность населения, чтобы определить динамику и основные паттерны.

## Актуальность
Актуальность исследования заключается в детальном рассмотрении аспекта рынка, касающегося непосредственно населения. Данное исследование может быть использовано для составления прогноза на следующие годы относительно экономического положения России. 

## Исследовательские вопросы
В каком месяце было выдано больше всего кредитов физическим лицам в России в 2025 году?
Какой регион является рекордсменом по выдаче кредитов физическим лицам?
Какой регион является рекордсменов по задолженности в 2025 году?
Какова общая задолженность физических лиц по кредитам сегодня?
Есть ли корреляция между месяцем и объемом выданных кредитов в России по регионам? 


## Данные
Данные взяты с сайта Банка России. Наборы содержатся в разделе “Кредиты, предоставленные физическим лицам - резидентам (региональный разрез)”. В наборах присутствует информация об объемах выданных кредитов физическим лицам и задолженности потребителей по всем регионам за каждый месяц. Данные были собраны в единую таблицу. Затем была проведена очистка: удалены пропуски, дубликаты, нормализованы форматы.

Файлы находятся в папке "data/".

## Анализ
Был проведен анализ в Google Sheets. Были рассчитаны следующие статистики: среднее, медиана, мода, минимальное и максимальное значения. Затем были определены топы и антитопы среди регионов по общему объему выданных кредитов и задолженности. Этот этап был сделан с помощью сортировки. Были созданы три сводные таблицы: объем кредитов по регионам, доля регионов  в объеме кредитов и объем и задолженность по округам. В первой сводной таблице были посчитаны суммарные значения объема выданных кредитов по регионам за каждый месяц, во второй сводной таблице были определены доли регионов в общем объеме выданных кредитов за каждый месяц, в третьей таблице регионы были сгруппированы по округам и были вычислены общие показатели по объему выданных кредитов и задолженности населения для каждого федерального округа.
